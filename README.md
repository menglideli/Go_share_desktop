# GoShare · 内网桌面共享

一个**单文件、免安装、无服务器**的局域网桌面共享工具：在一台电脑上点「我要分享」，
同事在自己电脑上点「我要观看」即可看到画面。专为公司内网 / 会议室投屏 / 结对排查设计。

- 单 exe 分发（约 18 MB），无需安装、无需管理员权限、无运行时依赖
- 无需服务器：两台电脑直连（WebRTC 局域网 P2P），画面不出内网
- 低延迟：DXGI 桌面采集 + MJPEG 增量编码，局域网内流畅 30~60 fps
- 全中文界面，双按钮入口，10 秒上手

## 快速开始

### 分享端（被看的一方）

1. 双击 `goshare.exe`，点 **「我要分享」**
2. 选择要分享的显示器（或点「框选区域」只分享屏幕的一部分），点 **「开始分享」**
3. 窗口自动最小化到托盘，界面上的 **IP 地址 + 授权码** 告诉同事即可
   （主窗最小化是刻意的：防止把自己的窗口采进画面形成"无限套娃"）
4. 想恢复窗口：双击任务栏右下角托盘的蓝圆图标；想结束：托盘右键 →「停止分享」

### 观看端（看的一方）

1. 双击 `goshare.exe`，点 **「我要观看」**
2. 输入分享端的 **地址**（如 `192.168.1.5:9000`）和 **授权码**，点「接入」
   —— 同一内网也可以点「扫描」，自动发现正在分享的电脑
3. 画面右上角可切换 **「适配 / 1:1」**：适配 = 缩放看全屏；1:1 = 原始像素看细节（可拖动平移）

### 分享中还能做什么

| 操作 | 说明 |
|---|---|
| 暂停分享 | 观众看到黑屏（1 fps 心跳，不会误以为断流）；再点恢复 |
| 更换区域 / 换屏 | 不中断分享，热切换到另一个区域或另一台显示器 |
| 轮换授权码 | 旧码立即失效，已接入的观众不受影响 |
| 踢出观众 | 观众列表里逐人踢出 |

## 防火墙说明（连不上时先看这里）

首次运行时 Windows 可能弹出「网络访问」确认框，**勾选「专用网络」并允许**即可。
如果被点了取消，或公司策略禁了弹窗，在分享端用**管理员终端**执行一次：

```bat
netsh advfirewall firewall add rule name="GoShare" dir=in action=allow protocol=TCP localport=9000
netsh advfirewall firewall add rule name="GoShare-UDP" dir=in action=allow protocol=UDP localport=50000-50100
netsh advfirewall firewall add rule name="GoShare-Discovery" dir=in action=allow protocol=UDP localport=45921
```

| 端口 | 协议 | 用途 |
|---|---|---|
| 9000（占用时自动顺延） | TCP | 信令：握手、授权码校验、观众管理 |
| 50000–50100 | UDP | WebRTC 媒体：实际的画面数据 |
| 45921 | UDP | 局域网自动发现（广播）；禁用后仍可手动输地址接入 |

观看端**不需要**任何防火墙改动（出站连接默认放行）。

## 常见问题

**观众连不上 / 卡在"连接中"**
九成是防火墙（见上节）。确认分享端界面上的地址与端口，先手动输地址排除自动发现的问题。

**观众看到全黑**
分享端是不是把窗口最小化后又手动关机/锁屏了？锁屏时桌面停止产出帧，属预期（锁屏 = 不共享）。
否则让分享端点一下「暂停」再恢复，观众侧会自动请求全量帧自愈。

**画面卡顿 / 模糊**
分享端把质量档位从「最大」降到「流畅 30」；观看端从「1:1」切回「适配」。
无线内网（Wi-Fi）丢包高时画面会短暂花屏后自愈，有条件走有线。

**高分辨率副屏上光标位置不对**
不会。程序内嵌 PerMonitorV2 DPI 感知清单，多屏混合缩放下坐标均为物理像素。
若真遇到，请把 `goshare.exe -log goshare.log` 产生的日志发给维护者。

## 命令行参数（进阶）

日常使用**不需要任何参数**。以下主要面向自动化与排障：

| 参数 | 说明 |
|---|---|
| `-port 9000` | 信令起始端口（被占用时自动顺延） |
| `-max 8` | 最多同时观看人数 |
| `-code 123456` | 固定授权码（默认每次随机） |
| `-display N` | 采集第 N 台显示器（默认主屏） |
| `-log 文件` | 日志写到文件（windowsgui 构建无控制台，排障时必加） |
| `-auto share / watch` | 无人值守模式（配合 `-addr` / `-code-watch`，供自动化验证） |
| `-key-interval 30s` | 周期性全量帧间隔（0 = 只靠观众请求恢复） |

## 从源码构建

```powershell
# 开发态（带控制台，便于看日志）
go build ./cmd/goshare

# 发布构建（单文件、无控制台、图标 + 版本信息 + DPI manifest）
powershell -File scripts/build.ps1 -Version 0.6.0
# 产出 dist/goshare-v0.6.0-windows-amd64.exe
```

技术栈：Go（CGO_ENABLED=0）· Gio（界面）· pion/webrtc（传输）· 标准库 MJPEG（编码）。
Windows 10 1809+（含 LTSC 2019）。

## 自检工具（开发用）

仓库内置一组 `cmd/` 自检/验证工具，改代码后跑一遍：

```powershell
go run ./cmd/capcheck      # 采集链路 12 项
go run ./cmd/codeccheck    # 编解码 14 项
go run ./cmd/sigcheck      # 信令 29 项
go run ./cmd/uicheck       # 界面离屏渲染 + 基线逐像素回归（-golden）
```
